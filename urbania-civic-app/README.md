# Urbania

Prototipo per la raccolta e la gestione delle segnalazioni civiche, realizzato con Expo, React Native Web e Leaflet.

## Struttura

- App.js: interfaccia dell'app e dati dimostrativi.
- - components/: mappe per web e dispositivi nativi.
  - - assets/: icone e risorse grafiche.
    - - presentation/: presentazione web interattiva.
      - - docs/: anteprima dell'applicazione.
       
        - ## Avvio locale
       
        - npm install
        - npm run web
